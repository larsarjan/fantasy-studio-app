# Vervallen: KNVB Apps Script

KNVB_FIXTURES wordt rechtstreeks handmatig beheerd met Ronde, Datum, Tijd, Thuisclub en Uitclub. De app leest uitsluitend gid 319573905 via de bestaande CSV-publicatie. Geen Apps Script uitvoeren en geen KNVB_IMPORT gebruiken. Verwijder, indien eerder aangemaakt, in Apps Script > Triggers uitsluitend de trigger met functie syncKnvbFixtures. Alle andere triggers ongemoeid laten.
